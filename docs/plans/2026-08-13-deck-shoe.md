# Deterministic DeckShoe Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use `executing-plans`, `test-driven-development`, `godot-development`, `godot-best-practices`, and `verification-before-completion` to implement this plan task-by-task.

**Goal:** Implement a deterministic six-deck Blackjack Shoe with top-first test injection, reproducible Fisher-Yates shuffle metadata, explicit exhaustion and the approved 20-card reshuffle boundary.

**Architecture:** `DeckShoe` is a typed pure-logic `RefCounted` beside `Card` and `HandEvaluator`. It owns a copied card array plus a draw cursor; runtime and injected construction are distinct static factories. `RoundController` remains responsible for round flow, refunds and replacing a Shoe between rounds.

**Tech Stack:** Godot 4.7.1, typed GDScript, gdUnit4 6.2.0.

---

**Files:**

**Step 1: Write failing top-first and defensive-copy tests**

Create tests proving an injected `[A♠, 10♥, 5♣]` draws in that exact order, reports remaining count and draw index, and is unaffected if the caller clears its original array.

**Step 2: Run RED**

```bash

  -s addons/gdUnit4/bin/GdUnitCmdTool.gd \
```

Expected: non-zero exit because `DeckShoe` is missing.

**Step 3: Implement the minimum injected Shoe**

Create a typed `RefCounted`, copy the supplied `Array[Card]`, store a draw cursor, and implement `create_injected`, `draw_card`, `remaining_count`, and `draw_index`.

**Step 4: Run GREEN**

Expected: injected tests pass and all existing HandEvaluator tests remain green.

### Task 2: Prove exhaustion never mutates the Shoe

**Files:**
- Modify: `tests/core/test_deck_shoe.gd`
- Modify after RED: `scripts/core/deck_shoe.gd`

**Step 1: Write failing exhaustion tests**

Draw the only injected card, then assert that another draw returns `null`, the cursor stays at `1`, remaining stays at `0`, `can_draw(1)` is false, `can_draw(0)` is true, and `can_draw(-1)` is false.

**Step 2: Run RED**

Expected: failure because exhaustion and `can_draw` are not implemented.

**Step 3: Implement the minimum boundary behavior**

Return `null` without advancing when exhausted; implement `can_draw` without changing state.

**Step 4: Run GREEN**

Expected: all DeckShoe and HandEvaluator tests pass.

### Task 3: Build and shuffle the approved six-deck runtime Shoe

**Files:**
- Modify: `tests/core/test_deck_shoe.gd`
- Modify after RED: `scripts/core/deck_shoe.gd`

**Step 1: Write a failing size and composition test**

Create a runtime Shoe, assert `312` cards, draw the complete Shoe and verify every one of the 52 rank/suit pairs appears exactly 6 times.

**Step 2: Run RED**

Expected: failure because runtime construction is missing.

**Step 3: Build the standard Shoe**

Add constants for 6 decks, 52 cards per deck and 312 total cards. Generate each suit/rank pair once per deck.

**Step 4: Write a failing shuffle reproducibility test**

Capture complete orders for two Shoes with the same seed and one with a different seed. Assert same-seed equality and different-seed inequality.

**Step 5: Run RED**

Expected: different seeds still yield the same unshuffled order.

**Step 6: Implement Fisher-Yates with a local seeded RNG**

Shuffle from the last array index through index `1`, choosing a swap index uniformly from `0...current_index`.

**Step 7: Run GREEN**

Expected: size, composition and reproducibility tests pass.
